Privacy Policy for Aura Prompt

1. Data Collection & Usage:
Aura Prompt accesses active webpage content solely to generate summaries, perform fact-checking, and extract entities upon explicit user request.

2. On-Device Local Processing:
All text processing and AI analysis are performed 100% locally on the user's device using Chrome's Built-in AI (Prompt API). No webpage content, user queries, or personal data are ever transmitted to or stored on external servers.

3. Data Sharing & Tracking:
Aura Prompt does not track user activity, sell user data, or share any information with third parties.
